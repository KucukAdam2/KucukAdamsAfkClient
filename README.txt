# KucukAdamsAfkClient

Windows için Electron + Mineflayer başlangıç projesi.

## EXE oluşturma (Windows)
1. Node.js LTS kur.
2. Bu klasörde terminal aç.
3. `npm install`
4. `npm run dist`
5. Çıktı `dist` klasöründe portable `.exe` olarak oluşur.

Notlar:
- Minecraft Java içindir.
- Offline hesap girişi yalnızca sunucu offline/cracked girişe izin veriyorsa çalışır.
- Sunucu sürüm desteği Mineflayer'ın desteklediği protokollerle sınırlıdır; listedeki her sürüm her Mineflayer sürümünde çalışmayabilir.
- Şu an otomatik yeniden bağlanma ve gelişmiş hareket/anti-AFK davranışları eklenmemiştir.
- Sohbet mesajları gösterilmez ve istemci mesaj göndermez.
- Sunucu kurallarına ve bot kullanımına ilişkin izinlere uy.
